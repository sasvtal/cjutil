# cjutil

C utility components inspired by commonly used Java-style APIs.  
All components follow a single-header-and-single-source design with no additional dependencies, allowing them to be easily integrated into other C projects.  
Simply copy the required `.h` and `.c` files into your project to use and compile them directly.

## hashtable.c / .h

A generic key-value container.  
See details in:  
[hashtable.md](doc/hashtable.md)

## vector.c / .h

A generic element container.  
See details in:  
[vector.md](doc/vector.md)

## strutil.c / .h

A string (`char *`) manipulation library.  
See details in:  
[strutil.md](doc/strutil.md)
